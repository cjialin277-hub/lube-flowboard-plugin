# Lube 影视画布 v2.0（Mac 独立分享版）· 3 分钟上手指南

欢迎使用 **Lube 影视画布 v2.0**！这套画布完全运行在你自己的 Mac 本地，**所有账号、项目、素材与积分都在你自己电脑上独立保存，互不串号**。

---

## 一、 开始前准备（仅需 2 样）

1. **Google Chrome 浏览器**（用于连接 Google Flow 账号）
2. **Node.js 18+**（如果电脑还没装，去 [https://nodejs.org](https://nodejs.org/) 下载 macOS LTS 版双击安装即可；Python 环境脚本会自动帮你配好）
3. *可选*：如需使用画布一键合片，建议安装 `ffmpeg`（终端运行 `brew install ffmpeg`）

---

## 二、 双击启动画布

1. 把压缩包解压到你喜欢的目录（例如「文稿」或「桌面」）。
2. 双击目录里的 **`一键安装并启动画布.command`**。
   - 若 macOS 提示“无法验证开发者”，**右键该文件 ➔ 点「打开」➔ 再点一次「打开」**即可放行。
   - 首次启动会自动安装前后端运行环境（约 1～2 分钟），之后每次双击都是秒开！
3. 启动完成后会自动用 Chrome 打开 **`http://localhost:5173`**，并弹出 **「首次绑定向导」**。

---

## 三、 跟着页面 3 步绑定你自己的信息

### 第 1 步：绑定 Google Flow（核心生图 / 生视频引擎）
1. 在弹窗里点击 **「复制路径」**，复制你电脑上的 `extension` 文件夹路径。
2. 在 Chrome 新标签页打开 `chrome://extensions`：
   - 打开右上角 **「开发者模式」**；
   - 点击 **「加载已解压的扩展程序」**（在弹出的文件窗口按 `⌘ + Shift + G` 粘贴刚才复制的路径回车确认）。
3. 打开 [https://flow.google.com/](https://flow.google.com/) 登录**你自己的 Google 账号**，新建一个空白项目并刷新页面——回到画布向导页，上方会自动亮起 **「扩展桥接已连通」** 绿灯。
4. 复制你刚才在 `flow.google.com` 打开的项目完整网址，粘贴进向导输入框点击 **「保存绑定」**。
5. 点选你的订阅等级（**Google AI Ultra** 或 **Google AI Pro**），点击即生效。

### 第 2 步：绑定 AI 分镜大脑（写提示词 / 画面分析 / 剧本规划）
- 如果你电脑装过 Claude / Gemini / Codex CLI，直接勾选即可；
- 如果没装 CLI，可以在 OpenAI 行填入你自己的 API Key；
- **如果暂时只想先手动填提示词出图出视频，直接点右下角「跳过此步，下一步」即可**，随时可在画布顶部 AI 按钮里补配。

### 第 3 步：可选引擎（Midjourney V7 / Meta Muse）
- 默认折叠，仅用 Google Flow 已经够拍完整短片；
- 如果你也有 Midjourney 或 Meta Muse 账号，点击「展开按需绑定」一键打开网页登录或填网关；
- 点 **「完成绑定，进入画布」** 立即开拍！

---

## 四、 日常管理与排错

- **停止画布**：双击目录里的 **`停止画布.command`**。
- **以后想换 Flow 账号 / 换项目 / 改 Ultra 或 Pro**：点画布左下角齿轮 **「设置」**，可实时热切换，也能点 **「重新打开新手账号绑定向导」**。
- **扩展提示离线怎么办？**：确认 Chrome 里只开着 **1 个** `flow.google.com` 标签页并刷新它，然后在 `chrome://extensions` 里点一下画布扩展的刷新图标即可。
