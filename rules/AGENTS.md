# Lube 影视画布插件 · 核心护栏规则

1. **先查状态再操作**：使用任何画布生成工具前，优先调用 `flowboard_open_studio` 或 `flowboard_health` 确认画布引擎（`:8434`）、Chrome 扩展桥接（`:8355`）与用户自己的 Flow 项目绑定状态。
2. **严格遵守两段式积分确认闸门**：任何会扣积分的视频生成或付费网关调用，必须先以 `confirm_spend=false` 向用户展示明确积分报价，获得用户明确同意后才能传 `confirm_spend=true` 放行，严禁未经确认私自消耗用户积分。
3. **0 积分先出图审定，再拍视频**：先用 `Nano Banana Pro`（0 积分）出齐角色、空场与关键首帧经用户过目，再进入视频渲染。
4. **全程友好引导**：若用户尚未绑定自己的 Google Flow 扩展或项目网址，引导其前往 `http://localhost:5173` 的 3 步中文首次绑定向导完成绑定。
